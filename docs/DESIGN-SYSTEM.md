# 界面、动效和角色规范

## 视觉方向

参考 LocalSend 的工具型布局：白色内容区、浅灰侧栏、青绿色操作色、大量留白。移除宣传横幅、英文标语、装饰轨道及重复说明。Mac 与 Windows 原样复用 ui/，不要另建界面分支。

左侧只设“接收、发送、设置”三个入口。接收页提供同步开关、筛选搜索、传输记录和底部输入区；发送页提供文件、剪贴板、大文件直传三个入口及设备列表，配对默认折叠；设置页集中连接、存储和清理，外观默认折叠。大文件是发送下的子页，带返回按钮。

## 尺寸与颜色

默认窗口 1130×850；侧栏 190px，内容左右边距38px。标题29px，正文12–14px，元信息10–11px。系统字体使用 SF/PingFang、Segoe UI/Microsoft YaHei。以 ui/styles.css 为唯一实现依据。

| Token | 值 | 用途 |
|---|---|---|
| --bg / --paper | #ffffff | 主背景 |
| --ink | #253238 | 正文 |
| --muted | #778187 | 辅助文字 |
| --green | #00868b | 主操作 |
| --accent | #e0f2f1 | 选中导航 |
| --line | #e8ecee | 分隔线 |
| 侧栏 | #f6f8f8 | 导航背景 |

圆角控件7–14px，选中导航为胶囊形。按钮保留 hover、active、focus-visible、disabled。状态同时提供文字，不只用颜色。空状态不注入假记录、假设备或假进度。

## 响应式与防重叠

角色只放侧栏底部，128×128px像素帧视窗，不参与主内容覆盖。窄窗口缩为112×112px，极窄窗口96×96px。仅CSS视口高度<=620px时隐藏角色和对白，恢复高度后自动显示，仍尊重手动关闭角色。人物始终占据独立侧栏空间，不覆盖正文或按钮。

<=880px：侧栏156px、内容边距27px；标题与开关、筛选与搜索允许换行；首页改为自然高度，避免内容裁切。<=560px：侧栏125px、内容边距20px；发送入口和设置行换行，输入区隐藏重复的粘贴按钮。筛选标签不逐字断行。

## 动效

页面进入250ms淡入并上移5px；控件反馈180–200ms。角色每状态5个不同画面，不再对静态人物做上下浮动。每张帧图为3列2行，按阅读顺序播放前5格，第6格为首帧副本，不参与播放。CSS background-size:300% 200%与steps(1,end)切帧，image-rendering:pixelated保留像素边缘。待机周期2.4秒，其余1–2秒，事件动作6.5秒后返回待机。

设置页选中动作在原地播放预览，侧栏同步切换；悬停也能预览。关闭动画或系统prefers-reduced-motion时停在第1帧，后台页面暂停播放。角色关闭不影响状态文字及传输功能。

## 角色素材

使用内置GPT Image生成10套像素帧图，共50个播放帧，统一银白双马尾、尖耳、绿眼、白金服装。粗像素轮廓、少量平涂色，避免精细插画。资产采用白色背景，通过multiply与浅色界面融合；不得宣称源文件具有透明通道。小角色仅提供状态陪伴，不承担主要信息。

| 文件 | 状态 | 反馈 |
|---|---|---|
| idle.png | 默认 | 今天，也慢慢来吧。 |
| wave.png | 点击角色 | 欢迎回来。 |
| copy.png | 复制 | 这份记忆，收好了。 |
| send.png | 本地入队 | 施一点小小的魔法。 |
| receive.png | 入站完成 | 你的文件，到了。 |
| success.png | 成功 | 好啦，已经完成。 |
| waiting.png | 等待 | 等一等，也没关系。 |

像素版本提示词和原图来源见 mascot-pixel-prompts.json，运行资产位于 ui/assets/mascot-pixel/。旧插画素材保留但不再由界面引用。

## 逐帧对齐

每帧以人物两脚中点与脚底为基准，坐标记录在 mascot-frame-anchors.json。每个512px单元先独立裁切，再通过CSS伪元素的translate将基准映射到显示框的(50%,94%)。不同窗口尺寸和64px预览共用比例坐标。禁止仅按规则网格切帧而忽略生成图里的位置偏差。庆祝、递信和搬箱的少量跳跃使用独立jump值保留。关闭动画时仍应用首帧校准；伪元素也必须尊重减少动态效果。

## 历史列表宽度与渲染（2026-09-18）

只保留最近 10 条记录。标题最多渲染 160 字符，单行省略，完整原文由原生端供复制使用。列表网格列使用 minmax(0,1fr)，行内为图标 / minmax(0,1fr) 正文 / 操作按钮三列；禁止让长英文、URL 或长路径撑开行宽。复制等按钮固定在右侧可见区域，列表不得出现横向滚动。
